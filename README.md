## ✨ Key Features & Capabilities

### 1. Multi-Page Immersive Application Architecture
The platform features 7 dedicated pages with seamless client-side routing, deep hash linking, and smooth animated transitions:
- **Home**: Futuristic hero section with live interactive metrics, animated glassmorphic feature showcases, value propositions, client logos, before/after preview, and interactive FAQs.
- **Services**: In-depth breakdowns of 9 core digital services with delivery timelines, feature checklists, and quantifiable business benefits.
- **Projects & Case Studies**: Categorized showcase of client deliverables with an **Interactive Before & After Transformation Slider**, tech stack tags, and client impact metrics.
- **Transparent Pricing**: Detailed comparison of 4 tier packages with interactive "Choose Plan" buttons pre-filling the consultation funnel.
- **About Us**: Founding story, mission narrative, company core values, company milestones roadmap (2024–2026), and founder profile.
- **Contact & Consultation**: Real-time validated quote inquiry form with automatic WhatsApp handoff and offline fallback support.
- **Secured Admin Lead Console**: Passcode-protected CRM console to monitor, cycle status, delete, seed, and export inquiries to JSON.

### 2. Interactive UX Components
- **Before/After Image Comparison Slider**: Mouse & touch interactive slider enabling prospective clients to inspect visual and technological transformations.
- **Direct WhatsApp Instant Handoff**: Auto-populates consultation details directly into WhatsApp (`+91 9479627447`) so leads connect with the founder in real-time.
- **Zero-Broken-Image Fallback (`SafeImage`)**: Resilient image wrapper rendering custom gradient cards with dynamic SVG icons and technical badges if external image URLs fail or are blocked.
- **Theme Switcher**: Full Dark Mode / Light Mode support with smooth transition classes, persistent `localStorage` memory, and tailored high-contrast color tokens.
- **Ambient Visual Effects**: Lightweight particle canvas background (`ParticlesBackground`) and radial cyan/blue glow orbs (`GlowBlobs`) matching the "Immersive UI" aesthetic.

- **Passcode**: `2026` (or `admin`)
- **Capabilities**:

## 🚀 Getting Started Locally

### Prerequisites
- **Node.js** (v18.0.0 or higher recommended)
- **npm** or **bun** or **yarn**

### 1. Clone or Open the Repository
```bash
git clone <repository-url>
cd <repository-directory>
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Start Development Server
```bash
npm run dev
```
The server will run on `http://localhost:3000` (or `http://0.0.0.0:3000`).

### 4. Code Quality & Linting
Validate syntax, types, and components:
```bash
npm run lint
```

### 5. Build for Production
Generate an optimized production bundle in the `dist` folder:
```bash
npm run build
```

### 6. Preview Production Build
```bash
npm run preview
```
